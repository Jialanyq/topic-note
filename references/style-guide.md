# 中文研究笔记的排版与去 AI 味指南

供 `topic-note` skill 使用。分三块：去 AI 味清单、结构模板、自检命令。

## 一、中文场景的去 AI 味清单

英文写作的 AI 痕迹检测规则（em dash 密度、rule of three、copula avoidance）搬到中文里，需要换成下面这些具体项。改的时候按"删除 > 降级 > 拆分"的顺序处理，不要整段重写。

### 必删

| 症状 | 典型表述 | 处理 |
| --- | --- | --- |
| 自我提示语 | 这正是关键、最值得拆解的一层、值得注意的是、不难看出、换句话说 | 直接删，让判断自己站出来 |
| 意义通胀 | 标志着、见证着、折射出、彰显了、为……奠定基础 | 改成具体动作或直接陈述结果 |
| 空洞总结段 | 未来可期、意义深远、值得持续观察 | 删，或换成一句具体的下一步 |
| 模糊引证 | 业内人士认为、有观点指出、多方消息显示 | 换成具体来源，或删掉这句 |
| 协作腔 | 希望这份整理对你有帮助、如需展开请告诉我 | 删，笔记不是对话 |
| 元叙述 | 本文将从三个方面展开、下面我们来分析 | 删，或压成半句"下面分五层拆" |

### 降级

- 加粗的行内小标题（`**位置：**……`）降为三级标题 `###` 或段落引导词
- 加粗只保留给术语：空间名、房型名、专有名词、被定义的概念
- 四级以上的标题层级不用，超过两层改用段落引导词

### 拆分

- 破折号：一篇里出现超过六次就要拆。中文破折号承担的是英文 em dash 的角色，密度过高是典型机器痕迹
- 长句：一句话里超过三个逗号分层，中间断一次
- 三段并列（rule of three）：中文里的"既……又……还……""不仅……而且……更……"是同一个毛病，改成两项或四项，或者直接陈述

### 保留

- "不是 X，而是 Y"的对偶句式：中文评论写作的常见修辞，保留几处是语气特征，全删会显得不像人写的
- 第一人称判断（"我认为""我倾向于"）：研究笔记里适度出现反而可信
- 不完整的想法与插入语：真人写作会有，不必修干净
- 行业黑话与内部口径：这是信息，不是毛病

### 判断标准

改完之后读一遍。如果每一句长度都差不多、每一段结构都一样、通篇没有一个具体的数字或专名，说明改过头了，成了另一种机器味。具体名词和数字是解药。

## 二、结构模板

```markdown
---
title: 一句能独立成立的话，含主体与核心反差
date: YYYY-MM-DD
tags:
  - 领域
  - 品类
  - 地域
skills:
  - humanizer
  - autoresearch
---

# 同 title

导语：三到四段。第一段给坐标与数字，第二段给反差，第三段给核心判断，
第四段交代本文路线（下面分几层拆）。

## 一、事实：这是谁，多大，谁做的
### 位置与规模
### 规格（房型、面积、产品线，用文字叙述，不用表格）
### 谁做的（设计方、创办人、背景）

## 二、产品：它卖什么
### 清单（一份，只出现一次）
### 每个条目承担什么角色（官方自称、命名逻辑）
### 交付物细节（房间、物料、可持续清单等）

## 三、在地性/背景：这些东西怎么进入产品
### 建筑 / 空间
### 材料与工艺
### 社区 / 生态位
### 自然 / 环境
### 文化 / 内容线
### 美学语言（一句话收口）

## 四、商业：钱从哪来
### 逐条收入线，每条一个小标题
### 扩张或复制路径

## 五、判断：这套模式成不成立
### 三个问题（为什么来、为什么多付、为什么可持续）
### 可迁移的做法（三到四条）

## 六、参照系：同类样本
### 样本 A
### 样本 B
### 横向比较（文字，不用表格）

## 附注：数据口径
逐条列出不采用的数字与原因，标注平台口径 / 现场观察口径 / 集团口径。

## 附：编辑与优化记录
三段：结构上改了什么、表述上清掉了什么、标题导语结尾怎么选出来的。
```

## 三、自检命令

交付前跑这三条。第一条必须输出 0，第二条必须无匹配，第三条用来核对结构。

```bash
f="<笔记文件绝对路径>"

# 1. 表格残留，必须为 0
grep -c '^|' "$f"

# 2. 摘抄与连载痕迹，必须无匹配
grep -n '前两期\|本期\|第三期\|短讯\|本报\|本文\|这一期\|系列\|上一版\|这一版\|原文' "$f"

# 3. 字数与章节结构
wc -m "$f"; grep -n '^#' "$f"
```

补充检查（人工过一遍）：

- 每个二级标题下面是否有至少一个三级标题或两段正文，没有说明这章是空壳
- 同一份清单是否只出现一次
- 新增内容是否在附录里交代了来源
- 导语第一段是否包含具体地名或数字
